## 🧠 Overview

SKlauncher 4.0 is a redesigned launcher for Minecraft: Java Edition, built around convenient management of game instances, mods, modpacks, and different Minecraft versions. Its refreshed interface brings frequently used tools together, making it easier to maintain multiple game configurations without mixing their individual settings and files.

The launcher supports vanilla and modded environments, popular mod loaders, integrated content installation, automatic Java management, account controls, and instance file access. It can handle a broad range of Minecraft releases, from older versions to current builds and snapshots, making it a versatile option for players with different types of setups.

## Additional Information for Windows Users

SKlauncher 4.0 is designed around an instance-based workflow, allowing players to maintain several Minecraft environments on the same PC. Each profile can have its own game version, mods, settings, worlds, and associated files, making it easier to switch between vanilla gameplay and heavily customized installations.

The launcher automatically handles the Java runtime required by individual Minecraft versions, reducing the need to configure Java manually. Integrated support for Modrinth and CurseForge also makes it possible to add compatible mods, modpacks, shaders, and resource packs directly through the launcher.

Version 4.0 is an open beta, so some functionality may continue to change as development progresses. Windows builds may also display a SmartScreen warning because beta releases are not currently code-signed.
